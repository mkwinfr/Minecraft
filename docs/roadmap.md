# Roadmap

## Milestone 1 (Current)

- Desktop-owned local runtime
- Bedrock install and lifecycle controls
- Telemetry, properties editing, and pack management
- Windows installer build path

## Milestone 2

- File manager workflows inside the launcher
- Desktop settings for startup, tray behavior, and managed paths
- Safer recovery for service failures and Bedrock crashes

## Milestone 3

- Backup and restore hooks
- Launcher self-update strategy
- Release hardening and distribution polish

## Out of scope

- Docker deployment
- Browser-first remote administration mode
- Running the product as a standalone public web service
